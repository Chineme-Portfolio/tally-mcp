# Radio & Switch

`Radio` for one-of-many (share a `name`); `Switch` for a single on/off that applies immediately. Both spring on activation and fill with the signature green.

```jsx
<Radio name="view" value="all" label="All tasks" defaultChecked />
<Radio name="view" value="open" label="Open only" />

<Switch label="Auto-reorder by status" defaultChecked />
```
